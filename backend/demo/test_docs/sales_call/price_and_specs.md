# Pricing

## Subscription
The platform costs $40 per user per month on the Business and Enterprise tiers, billed annually.

## Onboarding
Standard onboarding for 1-49 users is a $1,500 flat fee.
Standard onboarding for 50-99 users is a $2,500 flat fee.
Standard onboarding for 100 or more users is quoted per project.

# Technical specifications

## Integrations
The Enterprise tier integrates natively with HubSpot and Salesforce.

## API
The API rate limit is 1,000 requests per minute on the Enterprise tier and 300 requests per minute on Business.

## Security
We hold a SOC2 Type II report; the SOC2 security whitepaper can be shared under NDA.
